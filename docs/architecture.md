# アーキテクチャ

## 設計参考

**秋月電子 PIC簡易疑似電話交換機キット (L013)** を参考に、制御部をM5StampS3に置換した設計。

参考資料: [秋月電子 疑似電話交換機キット PDF](https://akizukidenshi.com/img/contents/kairo/%E3%83%87%E3%83%BC%E3%82%BF/%E3%81%9D%E3%81%AE%E4%BB%96/L013_%E7%96%91%E4%BC%BC%E9%9B%BB%E8%A9%B1%E4%BA%A4%E6%8F%9B%E6%A9%9F.pdf)

## 電源ドメイン

| ドメイン | 電圧 | 用途 | 分離方針 |
|----------|------|------|----------|
| `LOGIC_5V` | 5V (StampS3内蔵DC-DCで3.3Vに降圧) | M5StampS3、フォトカプラ出力側 | デジタルGND |
| `LINE_12V` | 12V DC | 電話回線給電、リレーコイル駆動 | デジタルGNDと共通 (初期試作) |
| `RING_HV` | AC 40-70Vpp @ 16Hz | リンガ信号 (トランス昇圧出力) | 絶縁トランスで分離 |

初期試作ではロジックGNDと電話回線GNDを共通にします。リンガ回路が非絶縁・非接地構成になる場合は、制御信号をフォトカプラ等で絶縁します。

**注意**: 12〜24VをStampS3の5V端子へ直接入力してはいけません。

## 機能ブロック (秋月キット→M5StampS3適合)

```text
                    ┌─────────────────────────────────────────────┐
                    │          M5StampS3 (ESP32-S3)              │
                    │                                             │
    5V入力 ─────────┤ 5V ──→ 内蔵DC-DC ──→ 3.3Vロジック         │
                    │                                             │
                    │ GPIO1  ←── PC1出力 (オフフック検出A)       │
                    │ GPIO3  ←── PC2出力 (オフフック検出B)       │
                    │ GPIO5  ──→ TR_A ──→ RL_A (回線リレーA)    │
                    │ GPIO7  ──→ TR_B ──→ RL_B (回線リレーB)    │
                    │ GPIO9  ──→ リンガ有効化信号               │
                    │ GPIO13 ──→ 16Hz矩形波 (リンガ周波数)      │
                    └─────────────────────────────────────────────┘

    12V入力 ─┬─→ リレーコイル電源 (RL_A, RL_B)
             │
             ├─→ CRD (E-153) ─→ 電話機A ─→ PC1 LED ─→ GND
             │
             ├─→ CRD (E-153) ─→ 電話機B ─→ PC2 LED ─→ GND
             │
             └─→ TA7250BP ─→ HP-124トランス ─→ リンガ出力
                 (23Wアンプ)   (12V:100V昇圧)   (40-70Vpp)

    電話機A音声 ←─→ RL_A ←─→ ST-71 ←─→ RL_B ←─→ 電話機B音声
                         (600Ω:600Ω トランス)
```

## GPIO割り当て (M5StampS3 PIN2.54版)

M5StampS3 PIN2.54版は10本のGPIOを2.54mmピンヘッダで提供:

| GPIO | 方向 | 機能 | 秋月キット相当 | 備考 |
|------|------|------|---------------|------|
| GPIO1 | 入力 | オフフック検出A | PC1 (TLP521-1) | Active-LOW |
| GPIO3 | 入力 | オフフック検出B | PC2 (TLP521-1) | Active-LOW |
| GPIO5 | 出力 | 回線リレーA制御 | RL2制御 | トランジスタ経由 |
| GPIO7 | 出力 | 回線リレーB制御 | RL3制御 | トランジスタ経由 |
| GPIO9 | 出力 | リンガ有効化 | PICポート | HIGH=有効 |
| GPIO13 | 出力 | リンガ16Hz矩形波 | PICポート | 16Hz出力 |
| GPIO15 | - | 予備 | - | 未使用 |
| GPIO43 | I/O | I2C SDA | - | 拡張用予約 |
| GPIO44 | I/O | I2C SCL | - | 拡張用予約 |
| GPIO46 | 入力 | 予備 | - | プルダウン済み |

## 回路ブロック詳細

### 1. 回線給電・オフフック検出

秋月キットの構成を踏襲:

```
LINE_12V ─── CRD (E-153, 15mA) ─┬─ TIP (RJ11)
                                 │
                                 └─ PC LED(+)

RING (RJ11) ─── PC LED(-) ─── GND

LOGIC_5V ─── R (10kΩ) ─┬─ PC Collector
                        │
                        └─ GPIO (MCU入力)

PC Emitter ─── GND
```

**動作**: 受話器を上げる(オフフック)とループ電流が流れ、フォトカプラLEDが点灯。トランジスタ側がONになりGPIOがLOWになる。

### 2. リンガ発生

秋月キットの構成を参考:

```
GPIO13 (16Hz) ─── C (0.1µF) ─── TA7250BP ─── HP-124 ─── RING_OUT
                                 (BTLアンプ)  (12V:100V)  (40-70Vpp)
```

**動作**: MCUから16Hz矩形波を出力し、オーディオアンプで増幅後、トランスで昇圧してベル信号を生成。

**安全注意**: 出力は40-70Vpp (SELV範囲外)。沿面距離、絶縁ケース、電流制限が必要。

### 3. 音声経路・回線切替

```
電話機A ←─→ RL_A ←─→ ST-71 ←─→ RL_B ←─→ 電話機B
                 (600Ω:600Ω)
```

**動作**: 通話確立時にリレーをONにし、トランス経由で音声を双方向に伝送。トランスによりDC分離・インピーダンス整合を実現。

## 秋月キットからの変更点

| 項目 | 秋月キット | M5StampS3版 |
|------|-----------|-------------|
| 制御IC | PIC16F84 (8bit, 4MHz) | ESP32-S3 (32bit, 240MHz) |
| 電源入力 | DC12V直接 | 5V (StampS3) + 12V (回線) 分離 |
| 水晶発振子 | 外付け4MHz | 不要 (内蔵) |
| 5Vレギュレータ | 78L05必須 | StampS3内蔵DC-DCで代替可 |
| Wi-Fi/OTA | なし | 対応可能 |
| DTMF検出 | なし | ソフトウェア実装可能 (Goertzelアルゴリズム) |

## 検証が必要な項目

### 電気的検証
- [ ] 3.3V GPIO出力でトランジスタ(2SC1815)を十分に駆動できるか
- [ ] TA7250BP入力感度 vs 3.3V MCU出力の整合 (レベルシフト要否)
- [ ] CRDの発熱 (12V × 15mA = 180mW)
- [ ] リレーコイル電流とトランジスタのIc_max

### 音声品質
- [ ] ST-71トランスの挿入損失
- [ ] 側音レベルの調整
- [ ] リレー接点バウンスによるノイズ

### リンガ
- [ ] トランス出力電圧の実測 (黒電話のベル負荷で変動)
- [ ] アンプ・トランスの発熱

### 安全
- [ ] 沿面距離・空間距離の確保 (リンガ高電圧部)
- [ ] 電流制限抵抗の発熱
- [ ] 入力サージ保護

## ファームウェア工程

1. ✅ 状態機械の骨格実装 (Idle→Seize→Ring→Connected)
2. ⬜ LEDとスイッチで状態機械を検証 (高電圧なし)
3. ⬜ リンガ許可信号のインターロックとウォッチドッグを追加
4. ⬜ Wi-Fi設定画面を追加
5. ⬜ ダイヤルパルス検出を追加
6. ⬜ DTMF検出を追加 (Goertzelアルゴリズム)
