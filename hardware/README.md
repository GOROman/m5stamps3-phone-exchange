# ハードウェア

設計CADはKiCadを使用し、JLCPCBでの2層FR-4基板製造を想定しています。

## 設計参考

**秋月電子 PIC簡易疑似電話交換機キット (L013)** の回路を参考に、制御部をM5StampS3に置換。

主要な参考部品:
- TA7250BP (23Wオーディオアンプ) → リンガ信号増幅
- HP-124 (100V:12V トランス) → 逆接続で12V→100V昇圧
- ST-71 (600Ω:600Ω オーディオトランス) → 音声経路結合
- TLP521-1 (フォトカプラ) → オフフック検出
- E-153 (定電流ダイオード) → 回線給電 (15mA)
- RD2N1UDC12 (2回路2接点リレー) → 回線切替

## 設計ブロック

1. **電源入力** - 5V (StampS3用) + 12V (回線/リレー用) 分離入力
2. **StampS3キャリア** - 2.54mm DIPソケット、プログラミングアクセス
3. **回線A給電・検出** - CRD + フォトカプラ構成
4. **回線B給電・検出** - CRD + フォトカプラ構成
5. **音声経路・切替** - ST-71トランス + DPDTリレー
6. **リンガ発生** - TA7250BP + HP-124昇圧

## 注意事項

### 電源分離

- StampS3の5V入力と回線用12Vは別系統
- 12〜24VをStampS3の5V端子へ直接入力してはいけない

### 高電圧安全

リンガ回路では **SELV範囲外の電圧 (40-70Vpp)** が発生します:

- 沿面距離: 最低3mm以上
- 空間距離: 最低2mm以上
- 電流制限抵抗を設置
- 露出端子は絶縁カバー必須
- 通電中の高電圧部には触れない

### RJ11端子

- `J2`: PRIVATE PHONE A
- `J3`: PRIVATE PHONE B
- 公衆電話網へ接続する端子は設けない

## Rev.A PCB

`m5stamps3_phone_exchange.kicad_pcb`は、80mm×60mmの初期レイアウト構想です。

- StampS3: 2.54mm DIPソケット
- J1: 電源入力 (5V + 12V分離)
- J2/J3: RJ11×2 (PRIVATE PHONE A/B)
- J4: GPIO/リンガ/音声拡張ヘッダ
- リンガ・音声回路領域: 予約エリア
