# M5StampS3 疑似電話交換機

M5Stack StampS3を使った、2回線対応の独立型アナログ疑似電話交換機です。

秋月電子の「PIC簡易疑似電話交換機キット」を現代化し、黒電話を含む2台の電話機で呼び出し・ベル鳴動・音声通話を行える装置を目指しています。公衆電話網（PSTN）には接続しません。

**設計やり直し中・発注禁止**

以前掲載した画像は手描きSVGであり、PCBやGerberからのレンダリングではありません。実データと一致しないため掲載を取り下げました。

## Rev.Bの設計資料

[Rev.B電気設計書](hardware/REV_B_DESIGN.md)に部品、端子接続、抵抗・コンデンサ定数、GPIO割当、呼出制御、評価手順を記載しました。

- M5StampS3は全端子を使う1.27mm接続版を採用する設計案です。
- Ag1171を2個使用し、5Vから回線給電・ベル生成・フック検出を行います。
- 音声はアナログ交差接続、呼出は20Hz・1秒鳴動／3秒休止です。
- 元の16Hzとの違いがあるため、黒電話の実機適合は未確認です。
- 電源保護・USB逆給電防止・独立ウォッチドッグは未確定です。
- **旧PCB、旧GPIO割当、既存ファームウェアはRev.B非対応です。**

呼出停止の[参照モデル](firmware/reference/ag1171_ring.h)と[単体テスト](tests/test_ag1171_ring.cpp)を追加しました。ホストで6つのテストブロックが合格しています。実機ファームウェアへの組込み、電気的検証、ERC/DRCは未実施です。

## 目標仕様

- RJ11電話端子×2
- M5Stack StampS3による状態制御
- 回線ごとのループ電流／オフフック検出
- 一方の電話機からもう一方を呼び出し
- 応答後の双方向音声通話
- 切断検出後に待機状態へ復帰
- Wi-Fi設定とOTAアップデートは将来拡張（Rev.B初版の範囲外）
- JLCPCBで製造可能な2層基板

## 電源系統（Rev.B案）

安定化5V・2A以上を目標とし、StampS3と2個のSLICを給電します。従来の独立24V案は廃止しました。入力5Vでも電話端子には高電圧が発生します。電源保護回路とUSB同時接続への対策が未確定のため、現状は通電・発注用資料ではありません。

## 安全上の注意

リンガ回路ではSELV（安全特別低電圧）の範囲を超える電圧が発生します。電流制限、沿面距離・空間距離、保護されたテストポイント、絶縁ケースを設けてください。通電中の高電圧部には触れないでください。
