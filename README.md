# M5StampS3 疑似電話交換機

M5Stack StampS3を使った、2回線対応の独立型アナログ疑似電話交換機です。

秋月電子の「PIC簡易疑似電話交換機キット」を現代化し、黒電話を含む2台の電話機で呼び出し・ベル鳴動・音声通話を行える装置を目指しています。公衆電話網（PSTN）には接続しません。

**設計やり直し中・発注禁止**

以前掲載した画像は手描きSVGであり、PCBやGerberからのレンダリングではありません。実データと一致しないため掲載を取り下げました。

## 目標仕様

- RJ11電話端子×2
- M5Stack StampS3による状態制御
- 回線ごとのループ電流／オフフック検出
- 一方の電話機からもう一方を呼び出し
- 応答後の双方向音声通話
- 切断検出後に待機状態へ復帰
- Wi-Fi設定とOTAアップデート
- JLCPCBで製造可能な2層基板

## 電源系統

- `LOGIC_5V`：StampS3用の安定化済み5V電源
- `LINE_12V`：電話回線給電・リレー駆動用の12V電源（秋月キット参考）
- `RING_HV`：ベル鳴動用の高電圧回路（TA7250BP + HP-124トランスで40-70Vpp生成）

12〜24VをStampS3の5V端子へ直接入力してはいけません。

## やり直しの完了条件

1. 元資料の回路を確認し、2回線の給電・検出・通話・呼出回路を部品定数付きで設計する。
2. メーカー資料に基づく部品番号とフットプリントを確定する。
3. 回路図からネットリストを作成し、PCBへ反映する。
4. 配線・絶縁距離・電源保護・起動時のリンガ停止を検証する。
5. ERC／DRCの結果を保存し、未接続と違反を解消する。
6. Gerberとドリルを出力して別ビューアで照合し、その実データからREADME画像を生成する。
7. 試作前レビューを完了する。実機動作確認前に動作保証とは表記しない。


## 安全上の注意

リンガ回路ではSELV（安全特別低電圧）の範囲を超える電圧が発生します。電流制限、沿面距離・空間距離、保護されたテストポイント、絶縁ケースを設けてください。通電中の高電圧部には触れないでください。

## 秋月キットからの主要変更点

| 項目 | 秋月キット | M5StampS3版 |
|------|-----------|-------------|
| 制御IC | PIC16F84 (8bit, 4MHz) | ESP32-S3 (32bit, 240MHz) |
| 電源 | DC12V単一 | 5V (StampS3) + 12V (回線) 分離 |
| Wi-Fi | なし | 対応可能 |
| OTA更新 | なし | 対応可能 |
